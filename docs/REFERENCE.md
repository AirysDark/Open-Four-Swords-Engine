# Technical Reference

## Zelda: A Link to the Past Research Reference

Reference repository:

https://github.com/camthesaxman/zeldaalttp

This project is NOT based on modifying the original code.

The repository is used only for studying engine concepts:

- Room and map architecture
- Entity behaviour
- Collision systems
- Enemy logic
- Combat mechanics
- Item systems
- Zelda-style gameplay structure
- Multiplayer ideas inspired by Four Swords

Open Four Swords Engine is a clean C++ rewrite with its own architecture.
