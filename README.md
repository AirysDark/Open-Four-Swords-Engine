# Open Four Swords Engine

Open-source C++ engine inspired by Zelda: Four Swords style gameplay.

This is a clean rewrite. The Zelda: A Link to the Past disassembly is used only as a technical reference for research into systems such as rooms, entities, collision, combat, and multiplayer concepts.

## Goals
- Modular C++ engine
- CMake build system
- Zelda-style action adventure mechanics
- Four player multiplayer architecture

## Development

Phase 1:
- Core game loop
- Renderer abstraction
- Input system
- Entity manager
